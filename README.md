# Vighnaharta Medical Foundation Website

> "Compassion and Healing" — A static website for Vighnaharta Medical Foundation

## Tech Stack
- **Next.js 14** (App Router)
- **Tailwind CSS v3**
- **Lucide React** icons
- **TypeScript**

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Pages
- `/` — Home
- `/about` — About Us
- `/programs` — Programs & Services
- `/impact` — Our Impact
- `/blog` — Blog & Resources
- `/get-involved` — Get Involved
- `/contact` — Contact Us
- `/terms` — Terms & Conditions

## Deployment
Deployed on [Vercel](https://vercel.com). Push to `main` branch for automatic redeployment.
